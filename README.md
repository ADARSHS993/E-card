# 🛒 E-Card

A modern Android E-Commerce application built using **Kotlin** and **Jetpack Compose**. This project follows modern Android development practices and is currently in the initial development phase.

## 🚧 Project Status

This project is under development.

### ✅ Completed
- Login Screen UI
- Sign Up Screen UI
- Navigation between Login and Sign Up screens
- Material 3 UI Design
- Jetpack Compose UI

### 🚀 Coming Soon
- Firebase Authentication
- Home Screen
- Product Listing
- Product Details
- Shopping Cart
- Wishlist
- Checkout
- Payment Integration
- User Profile
- Order Management

## 🛠 Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Android Studio

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/ADARSHS993/E-card.git
```
2. Open the project in Android Studio.

3. Sync Gradle and run the application.
